# Ingredient Knowledge（食材知识）

> Reference data for generating「价值/做法」and answering「某类食材怎么吃/怎么搭」questions.
> Organized by 食材类（food category）；each category has three parts：
> **① 特性（客观事实）→ ② 提味原理（通用方法）→ ③ 安全建议（基于事实的可执行建议）**
> All content is **general cross-user knowledge** — informational, not medical advice.

## 使用方式

- 用户点名某类食材问「怎么吃/怎么搭」，或生成「价值/做法」时：先定位食材所属类别，读该类的三件套。
- 本文件只提供「这类食材本身怎么处理、有什么注意」，**不提供固定食谱/跨食材组合**——那是每日搭配生成器结合用户画像与库存动态产出的。
- 安全建议是通用级（「控钠人群」「控糖人群」），落到具体用户时用 `profile.json` 过滤（如用户肝功能不佳 → 控钠建议生效）。

## 水溶性膳食纤维类（无味型：海带、木耳、银耳、魔芋）

### ① 特性（客观事实）

| 食材 | 关键成分 | 纤维 / 营养特点 |
|------|---------|----------------|
| 海带 | 褐藻胶（可溶性） | 控糖控脂；含碘、含钠 |
| 木耳 | 木耳多糖 + 不溶性纤维为主 | 促肠道蠕动 |
| 银耳 | 银耳多糖（可溶性） | 吸水成胶、润肠 |
| 魔芋 | 葡甘聚糖（高度可溶性） | 近零碳水、近零热量、强饱腹 |

共同点：高纤维、低热量、本身无味 → 是「风味载体」，味道由调料与搭配食材提供。

### ② 提味原理（通用方法）

这类无味食材靠「**酸 + 香 + 鲜 +（辣）+ 几滴好油**」给味，不靠糖和重油：

- **酸**：醋 / 柠檬——最有效，解腻提味，还辅助控糖
- **香**：蒜、洋葱、香菜、姜等辛香食材
- **鲜**：少量酱油 / 菌菇 / 海带自带鲜味
- **油**：橄榄油或香油几滴（不饱和脂肪，控 LDL 友好）

> 给味原则：靠酸香鲜，不用糖（升糖）也不用重油（升 LDL、伤肝）。

### ③ 安全建议（基于事实的可执行建议）

- **木耳 / 银耳**：干品泡发须**冷藏、短时、现泡现吃**，绝不室温隔夜久泡（米酵菌酸中毒风险）。
- **海带**：泡发后仍含一定钠——控钠人群（肝病、高血压）凉拌/煮汤时酱油盐减半；碘含量高，甲状腺正常者适量无碍，勿长期超量。
- **魔芋**：葡甘聚糖吸水膨胀极强——一餐别过量（易胀气），餐后多喝水。

## 绿叶菜类（叶菜：苋菜、红薯叶、菠菜、小油菜、生菜、鸡毛菜、空心菜等）

### ① 特性（客观事实，含季节产出）

| 食材 | 时令（季节产出） | 关键成分 | 营养特点 |
|------|----------------|---------|---------|
| 苋菜 | 夏–初秋（6–9月）最佳 | 铁、钙、β-胡萝卜素、叶黄素 | 铁钙居叶菜前列；草酸偏高 |
| 红薯叶 | 夏–秋（6–10月） | β-胡萝卜素（维A）、维C/E、多酚 | 抗氧化强、高钾高纤维 |
| 菠菜 | 秋–春（10月–次年4月） | 铁、叶酸、β-胡萝卜素 | 草酸高，需焯水；夏菠菜味涩 |
| 小油菜 | 秋–春（9月–次年4月） | 钙、维C、叶酸 | 钙丰富、草酸较低 |
| 生菜 | 全年，春秋最佳 | 维C、叶酸 | 可生食 |
| 空心菜 | 夏（5–9月） | 维C、钾、膳食纤维 | 入秋渐老 |
| 鸡毛菜 | 全年（春秋尤盛） | 维C、膳食纤维 | 嫩叶菜 |

共同点：低 GI、高膳食纤维（不溶为主 + 少量水溶）、高钾高抗氧化、低脂低热量。

### ② 提味原理（通用方法）

叶菜本身清苦/带涩，靠「**焯水去涩 + 酸香鲜 + 几滴好油**」给味：

- **焯水**：苋菜、菠菜、空心菜等草酸高者必焯，去草酸、去涩
- **酸**：醋 / 柠檬（可生食的叶菜如生菜更直接用酸）
- **香**：蒜、洋葱等辛香食材
- **油**：橄榄油或香油几滴（助脂溶性维生素吸收，不饱和脂肪友好）

> 给味原则：靠酸香鲜，不用糖（升糖）也不用重油（升 LDL、伤肝）。

### ③ 安全建议（基于事实的可执行建议）

- **苋菜 / 菠菜**草酸偏高：务必焯水去草酸，促进钙铁吸收、去涩。
- **叶菜普遍含钾较高**：肝功能不佳者若合并肾功能异常需控钾（咨询医生）。
- **缩短加热**：能生吃（生菜）不焯、能焯水不蒸，尽量保留维 C/叶酸。
- **茎老选嫩**：空心菜、红薯叶、苋菜入秋后茎渐老，宜选嫩尖。
